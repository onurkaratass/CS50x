## 📂 Curriculum & Project Breakdown

| Directory | Core Topics & Focus | Key Concepts & Technologies |
| :--- | :--- | :--- |
| **Week 1** | C Fundamentals & Logic | Conditionals, loops, arithmetic operators, data types |
| **Week 2** | Arrays & Cryptography | Arrays, strings, memory buffers, command-line arguments, ciphers |
| **Week 3** | Algorithms & Complexity | Selection sort, bubble sort, merge sort, recursion, $O(n)$ notation |
| **Week 4** | Memory & Pointers | Dynamic allocation (`malloc`, `free`), pointers, memory leaks, file I/O |

| **Week 6** | Python | High-level scripting, data processing, regex, Pythonic paradigms |
| **Week 7** | SQL & Relational Databases | Database schemas, indexing, JOIN operations, subqueries, ACID |
| **Week 8** | HTML, CSS, JavaScript | DOM manipulation, async JavaScript, event listeners, layout styling |
| **Week 9** | Full-Stack Development | Flask framework, Jinja templating, session state, REST endpoints |
| **Final Project** | Browser Extension | **Focus & Site Blocker**: Chrome Manifest V3, `declarativeNetRequest`, service workers |

## 🚀 Final Project: Focus & Site Blocker
* A productivity-focused Chrome extension combining a Pomodoro interval timer with network-level website blocking.
* **Tech Stack:** JavaScript (ES6+), Manifest V3, Chrome Storage API, Declarative Net Request API.
* **Key Feature:** Dynamic domain redirection to an internal notification interface without degrading browser performance.

## 🇹🇷 Türkçe Özet

Bu repo, **Harvard Üniversitesi CS50x: Bilgisayar Bilimleri** eğitim programı (Haziran 2026 – Eylül 2026) boyunca geliştirdiğim tüm haftalık algoritmik çözümleri, veri tabanı çalışmalarını ve bitirme projemi içermektedir.

### 🌟 Kazanımlar ve İşlenen Konular
* **Düşük Seviyeli Sistem & Bellek (C):** İşaretçiler (pointers), dinamik bellek tahsisi (`malloc`/`free`), bellek sızıntılarının Valgrind ile tespiti ve dosya manipülasyonu.
* **Veri Yapıları & Algoritmalar:** Bağlı listeler (linked lists), hash tabloları, ağaç yapıları (tries) ve algoritmik karmaşıklık ($O(n)$, $O(1)$) optimizasyonu.
* **Backend & Veri Yönetimi:** Python ile betik yazımı, SQLite ile ilişkisel modelleme, Flask ile API ve oturum yönetimi.
* **Bitirme Projesi:** Modern Chrome Manifest V3 standardında, ağ filtreleme kuralları ve arka plan servis çalıştırıcıları (service worker) barındıran odaklanma ve web sitesi engelleme eklentisi.
